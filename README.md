# Data Cleaning Practice Project

This repository contains my hands-on practice on Data Cleaning and Data Preprocessing using Python.  
It is based on a structured learning series of 5 courses.

## 📚 What I Learned
- Handling missing values
- Data formatting and standardization
- Removing duplicates and noise
- Feature cleaning and transformation
- Basic exploratory data analysis (EDA)

## 🛠️ Tools Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

## 📂 Project Structure
The project is divided into multiple parts based on course progress:
- Part 1: Initial data cleaning concepts
- Part 2: Advanced preprocessing techniques

## 🎯 Goal
To build strong foundational skills in data preprocessing for Machine Learning and Data Science applications.
